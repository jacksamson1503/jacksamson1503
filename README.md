## 👨‍💻 About Me

I'm a **Junior DevOps & Cloud Engineer** who loves turning manual, error-prone work into **automated, repeatable, observable systems**. I design CI/CD pipelines, provision cloud infrastructure with Terraform, containerize applications, and monitor everything that runs in production.

```yaml
name: Jack Samson

currently_learning: [Amazon EKS, Helm, Argo CD, GitHub Actions]

philosophy: "If you do it twice, automate it."
```
